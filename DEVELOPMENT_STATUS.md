# Astra VPN — статус разработки

## Реализовано в текущей ветке

- Android-клиент на Kotlin, minSdk 24 / targetSdk 35.
- Интеграция Android libbox (sing-box 1.14.3) и VPN-службы на базе `VpnService`.
- Создание TUN-интерфейса через Android `VpnService.Builder`, маршруты IPv4/IPv6 и DNS.
- Обработка смены сети через `ConnectivityManager.NetworkCallback`.
- Импорт VLESS, Hysteria2 и TUIC URI, загрузка HTTPS-подписок с ограничением размера и проверкой конфигурации.
- Хранение профилей с шифрованием AES/GCM через Android Keystore.
- Отображение состояния VPN, серверных профилей и TCP-проверки доступности VLESS-узлов.
- Debug APK собирается в GitHub Actions.

## Ограничения и обязательная проверка

- Успешная CI-сборка подтверждает компиляцию и целостность APK, но не доказывает подключение к реальным серверам.
- TCP-проверка VLESS показывает только доступность TCP-порта, а не задержку внутри VPN-туннеля. Для Hysteria2/TUIC этот тест не применяется.
- Страна определяется только по явно указанному имени/тегу профиля; если достоверного обозначения нет, показывается нейтральный значок.
- Совместимость всех вариантов транспорта и параметров подписок Velvet VPN ещё требует проверки на реальных конфигурациях.
- Переподключение, переход Wi-Fi ↔ мобильная сеть, поведение в фоне, Android 14/15 и фактическая скорость должны быть проверены на физическом устройстве.
- Не публиковать VPN-ссылки, UUID, пароли, Reality-ключи или приватные токены.
