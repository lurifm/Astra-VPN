# Astra VPN

Android VPN client на Kotlin, использующий sing-box / libbox.

## Уже реализовано

- Импорт VLESS, Hysteria2 и TUIC share-ссылок и HTTPS-подписок.
- VPN-туннель на базе Android VpnService и sing-box.
- Отдельный sing-box URL-test: HTTP-запрос выполняется через каждый импортированный proxy-outbound, не перезапуская основной VPN-туннель.
- Для профилей без успешного URL-test результата отображается «н/д»; нулевые промежуточные значения не считаются успешной задержкой.
- Дополнительная TCP-проверка DNS и TCP handshake для VLESS endpoint; итог пяти попыток — медиана успешных измерений.
- Сортировка по измеренной задержке; профили без результата находятся внизу.
- Проверка HTTPS-доступности через активную Android VPN Network.
- Предупреждение, если VPN-интерфейс создан, но интернет через VPN не подтверждён.
- Настройки маршрутизации приложений, избранное, фильтр и поиск серверов.
- Зашифрованное хранение профилей с Android Keystore.
- CI: unit tests, debug APK build и публикация APK как GitHub Actions artifact.

## Важно о показателе задержки

URL-test — это время HTTP-проверки через соответствующий proxy-outbound до контрольного HTTPS endpoint. Это не ICMP ping. Дополнительный показатель «TCP … мс» относится только к TCP handshake с VLESS endpoint и не является задержкой всего VPN-маршрута. Для Hysteria2/TUIC TCP-показатель не подставляется вместо реальной UDP-проверки.

Скорость соединения не ограничивается приложением искусственным rate limit. Фактическая пропускная способность зависит от сети оператора/Wi-Fi, сервера, маршрута и параметров протокола. Перед выводами о скорости нужны испытания на физическом устройстве.

## Текущий статус

Проект активно разрабатывается. Debug APK предназначен для тестирования; для распространения потребуется отдельная release-сборка, подпись и проверка на реальном устройстве.

## Первая десятка улучшений Astra

В интерфейсе и базовой логике проекта реализованы следующие элементы:

1. Выбор лучшего измеренного сервера по результатам sing-box URL-test с учётом недавних отказов и стабильности.
2. Импорт поддерживаемых ссылок и HTTPS-подписок из буфера обмена одной кнопкой «Добавить».
3. Плитка Astra VPN в быстрых настройках Android.
4. Автоматическое обновление подписок по заданному интервалу и при открытии приложения (если включено в настройках).
5. Понятные сообщения об ошибках и тайм-аут для зависшего состояния обновления подписки.
6. Тёмная минималистичная цветовая схема.
7. Четырёхконечная звезда как главная кнопка подключения, с разным состоянием и пульсацией при активном соединении.
8. Анимированное созвездие в карточке подключения: звёзды и линии мягко оживают при подключении.
9. Звёздный маркер у каждой орбиты в списке; оттенок показывает качество измеренной задержки, обводка — выбранный/активный сервер.
10. Тематические подписи «Орбиты», «Запуск», «Посадка», «Прыжок» без замены понятных системных статусов.

Пункты 1–7 используют уже существующую функциональность проекта; пункты 8–10 добавлены в рамках космического оформления. Наличие исходного кода не заменяет проверку APK на физическом Android-устройстве.

## Вторая десятка улучшений Astra (11–20)

- **11. Цветовая тема:** глубокий тёмно-синий фон, холодные синие/фиолетовые поверхности и единый светлый акцент; палитра применяется в основном экране и Material-теме.
- **12. Анимация запуска:** при нажатии звезда сжимается и вспыхивает, вокруг неё расходится световое кольцо; сохранена тактильная отдача.
- **13. Первое знакомство:** добавлено трёхэкранное обучение со слоганом «Своя орбита. Своя скорость. Своя защита». Можно пройти, пропустить; повторно автоматически не показывается.
- **14. Иконка:** обновлена на светящуюся четырёхконечную звезду на тёмно-космическом фоне.
- **15. Отклик:** используется haptic feedback главной кнопки и плавная анимация её нажатия/состояния.
- **16. Пресеты маршрутизации:** добавлены быстрые варианты «Весь трафик», «Только мессенджеры», «Только браузеры». Список определяется по пакетам приложений, найденным на устройстве; пользователь подтверждает выбор кнопкой «Сохранить».
- **17. Скорость и IP:** добавлен единый тест внешнего IP и скорости загрузки небольшого тестового файла. При активном VPN запросы идут по текущему маршруту устройства; результат зависит от сети и контрольного узла и не является гарантией максимальной пропускной способности.
- **18. Статистика:** в проекте уже есть текущая скорость upload/download, график, средние/пиковые значения и дневная/недельная сводка трафика. Разбивка по отдельным приложениям пока не реализована.
- **19. Резервная копия:** уже доступны зашифрованный паролем экспорт и восстановление профилей/подписок через файл. QR-экспорт полного набора настроек пока не реализован.
- **20. Поделиться сервером:** добавлена отдельная кнопка отправки ссылки выбранного сервера через системное меню Android. QR-представление ссылки пока не реализовано.

Проверка исходного кода подтверждает внесение этих изменений. APK-сборка и проверка анимаций/сетевых тестов на физическом устройстве в рамках этого изменения не подтверждены.

## Улучшения 21–30

- **21. Уведомления подписок:** предупреждения об истечении срока и остатке трафика; уведомления появляются при проверке подписок во время открытия приложения.
- **22. Сетевая безопасность:** диагностический экран показывает VPN-транспорт, DNS и IPv6-маршрут; системный Kill Switch включается пользователем в настройках Android.
- **23. Виджет и ярлыки:** виджет рабочего стола показывает состояние VPN, быстрые ярлыки открывают приложение и запускают подключение.
- **24. Английский язык:** добавлены английские ресурсы для части интерфейса, виджета, ярлыков, уведомлений и диагностики; полная локализация ещё продолжается.
- **25. Проверка сервисов:** HTTPS-проверка доступности YouTube, Telegram и ChatGPT через текущую активную сеть.
- **26. Протокольный fallback:** после нескольких последовательных ошибок проверки туннеля Astra сначала рассматривает серверы с другим поддерживаемым протоколом (VLESS, Hysteria2 или TUIC); если таких профилей нет, использует обычный подбор альтернативного сервера.
- **27. Экономия батареи:** настройка уменьшает частоту обновления сетевого мониторинга и запуска проверки состояния туннеля с 1 до 4 секунд.
- **28. Повторное обучение:** трёхэкранное знакомство можно повторно открыть из настроек.
- **29. Обратная связь и журнал изменений:** добавлен экран «Что нового» и системное меню отправки отзыва, в котором можно выбрать Telegram, если он установлен.
- **30. Пасхалка:** семь быстрых нажатий на надпись ASTRA VPN открывают секретную орбиту.

Функции, зависящие от Android, сети и установленных приложений, требуют проверки на реальном устройстве. Протокольное переключение выполняется только после повторных неудачных проверок и не гарантирует восстановление связи, если все доступные профили недоступны.

## Улучшения 31–35

- **31. Автоматическая диагностика:** отчёт сопоставляет состояние сети, подтверждение интернета Android, VPN-транспорт, DNS и результат проверки туннеля, затем предлагает конкретные шаги. Диагностика не доказывает отсутствие утечек.
- **32. Прогноз трафика:** показывает средний суточный расход по двум–шести завершённым дням из локальной истории. Это ориентир по общему трафику устройства, а не точный прогноз лимита подписки.
- **33. Оценка надёжности:** рассчитывает прозрачный ориентировочный балл по сохранённым событиям подключений и ошибок; рядом указывается уровень уверенности. Это не рейтинг uptime провайдера.
- **34. Интерактивная карта орбит:** серверы показаны как звёзды; касание звезды выбирает соответствующий профиль. Цвет использует последнюю измеренную задержку, серый означает отсутствие данных.
- **35. Captive portal:** Astra распознаёт системный признак Android для сетей, требующих авторизации, и добавляет рекомендацию открыть браузер и завершить вход.

Прогноз и оценка надёжности требуют накопления локальной истории. Карта показывает до 36 профилей за один раз. Физическая проверка интерфейса и поведения captive portal на разных версиях Android ещё необходима.
